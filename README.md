# 情绪探索站

面向初中生的 50 分钟情绪科普互动课堂，支持电脑投影与手机查看。

## 打开课堂

- 在线版：https://kongbaipsy-lab.github.io/emotion-explorers-classroom/
- 离线版：下载 `offline.html`，用浏览器打开；图片、音频、视频已内置。首次下载需要网络，保存后可以离线播放。
- 电脑使用方向键切换内容，可打开全屏、课程地图和教师提示。

## 课程内容

认识情绪、理解情绪、练习调节、支持与求助。包含理论、情境讨论、有声观察练习、视觉小游戏和同伴支持示范。总时长 50 分钟，允许学生选择不分享。

## 文件

`index.html`、`app.js`、`style.css` 为网页源码；`assets/` 为配图；`media/` 为课堂媒体。无需安装依赖或登录即可使用。参考资料链接需要联网，课堂播放不依赖这些链接。

## 当前媒体状态

本版本包含中文合成语音与 AI 生成插画。观察练习和短片尚未完成授课者音色替换；同伴支持字幕动画目前无配音，可选用另一个有声短片。原始个人录音、声音克隆样本、模型、账号凭据未纳入本仓库。

本课用于心理科普，不替代个别心理评估与治疗。GitHub Pages 在不同地区和网络下的可访问性不同，本项目不承诺中国大陆各网络均能稳定访问。
