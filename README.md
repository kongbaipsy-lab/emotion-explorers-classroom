# 情绪探索站 · 50分钟练习课堂

面向初中生的情绪科普互动课堂，支持电脑投影、手机查看和离线播放。

## 打开与使用

- [在线课堂](https://kongbaipsy-lab.github.io/emotion-explorers-classroom/?v=practice-20260915)
- [完整离线版](offline.html)：下载文件后用浏览器打开，无需安装、登录或在线合成。
- [50分钟授课流程与课前准备](教学流程.md)
- [打印方法卡（每页4张）](method-card.html)

方向键切换画面；课程地图可跳转；教师提示包含每页时长、带领话术、追问及备课理论。

## 课程目标与结构

说清感受、选择一个行动、找到支持。七个环节、25个画面，总计50分钟。27—39分钟为核心表达练习：先试一次、同伴反馈、学方法、修改再试、前后对照。保留情绪词卡、身体信号图、三格情境图、情绪作用图卡和支持地图；详细理论置于教师提示。

每个人可以独立想、同桌交流、书写或旁观。方法卡只在当前页面内存中保留，不存储、不上传，刷新即清空。活动不是心理诊断或评分工具。

## 预制媒体

两段60秒练习及45秒备用短片旁白使用授课者授权音色，通过本地Qwen3-TTS合成。约30秒双人对话中，一位使用授课者音色，一位使用另一虚拟合成音色；字幕、暂停与重播按实际音频同步。原始录音、参考样本、模型及账号凭据未公开。

课堂只播放预制音频，不运行AI模型，不接入现场AI问答。图像为此前制作的AI插画，图示与课堂情境为原创教学改编。引用资料链接放在教师提示，需要联网阅读；课堂媒体无需依赖这些链接。

## 源码

`app.js` 是基础课堂与播放器，`teaching.js` 是教学图示，`workshop.js` 定义当前练习流程；对应CSS负责排版。`assets/` 和 `media/` 为课堂成品素材。

本课用于科普，不能替代个别评估或治疗。GitHub Pages 在中国大陆不同网络下的可访问性可能不同；上课建议准备离线版，并在实际设备上试播。
